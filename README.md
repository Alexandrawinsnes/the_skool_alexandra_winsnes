# the_skool_alexandra_winsnes

--- Syfte
Syftet med denna labb är att applicera dina kunskaper inom SQL för att hjälpa utbildningsanordnaren The Skool att navigera i myndighetens beslut. The Skool får på så vis ett stöd i att dra relevanta datadrivna beslut.

--- Bakgrund
För att en utbildningsanordnare ska få bedirva YH-utbildningar (program eller kurser) med statligt finansiellt stöd krävs att de ansöker om att bedriva  specifikt program eller kurser. För varje ansökan krävs att man beskriver hur kursen är förankrad i arbetslivet och att behovet finns för studerande som löst kursen och programmen. För förankringem i arbetslivet krävs ett visst antal perosner från arbetslivet i relevant område som kan bestyrka behover.
